# VSSUT Satsang Website

A full-stack web platform developed for **VSSUT Satsang** to provide information about Satsang activities, devotional resources, bhajans, events, alumni, and yearly gallery memories.

The project includes a responsive public website along with an admin dashboard for managing website content.
Features
##Public Website

- Responsive and user-friendly website
- Satsang information and event details
- Bhajan and lyrics section
- Search functionality for bhajans/lyrics
- Alumni section
- Year-wise Satsang gallery
- Devotional resources
- YouTube video integration
- Contact and information pages
- Responsive design for desktop and mobile devices
- Dark-themed user interface

### Admin Dashboard

- Secure admin login
- Admin authentication using Spring Security
- Password hashing using BCrypt
- Admin-only content management
- Add new bhajans
- Edit existing bhajans
- Delete bhajans
- Upload and manage gallery images
- Manage gallery content
